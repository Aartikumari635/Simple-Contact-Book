
# 📒 Simple Contact Book

A  Java Swing-based Contact Book application developed to manage contact information through a simple and user-friendly graphical interface.

## ✨ Features

- ➕ Add new contacts
- 🔍 Search contacts by name
- 📋 View all saved contacts
- 🗑️ Delete selected contacts
- ✅ Phone number validation (10 digits)
- 📧 Email address validation
- 🎨 Colorful and user-friendly GUI

## 🛠️ Technologies Used

- **Programming Language:** Java
- **GUI:** Java Swing
- **IDE:** NetBeans
- **Data Storage:** ArrayList

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project in NetBeans.
3. Create or open `SimpleContactBook.java`.
4. Ensure the filename and public class name match.
5. Run the `SimpleContactBook` class.

## 📸 Application

The application provides a graphical interface to add, search, view, and delete contacts.

## ⚠️ Note

Contact information is stored in memory using an ArrayList. Data is not permanently saved and will be lost when the application closes.
